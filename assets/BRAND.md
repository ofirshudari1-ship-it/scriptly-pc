Splash screen (`app/splash.py`) uses a fixed dark palette independent of
theme (`#0f1420` bg / `#00b8ae` accent) since it appears before the user's
theme preference has loaded from config.

## Typography

`Segoe UI` (Windows-native, full Hebrew+English glyph coverage). No custom
font is bundled — relies on the OS default, which is guaranteed present on
every supported Windows version (see `README.md` requirements).

## Icon

`assets/icon_idle.ico` / `icon_idle.png` — teal soundwave mark in a navy
circle with a white checkmark badge (bottom-right, "tasks done"). A red
variant (`icon_recording.*`) swaps the badge accent for the active-recording
state (tray icon, overlay). Generated by `build/generate_icons.py`
(Pillow-drawn, no external asset dependency) — multi-resolution `.ico`
(16/32/48/64/128/256) + transparent `.png`.

## Known gaps vs. the shared cross-tool standard

`_AUDIT/STANDARDS.md` §3 calls for a shared `design-tokens.json` (spacing,
radius, shadow, motion scale) referenced by all 11 tools, with each tool
swapping in only its own palette. That shared file does not exist yet
anywhere in the workspace — it's a cross-cutting initiative spanning every
tool, not something to invent unilaterally inside one tool's folder. This
document captures Scriptly PC's actual palette so it's ready to plug into
that system once/if it's created at the workspace level.
